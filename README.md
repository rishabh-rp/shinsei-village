
# SHINSEI VILLAGE

A creative landing page built using HTML and CSS, featuring cinematic backgrounds and custom typography.

## Built With

- HTML5
- CSS3
- Remix Icon

## Features

- Custom navigation bar with social media icons
- Background image with gradient overlay
- Curved section design using clip-path
- Vision section with a decorative divider
- Clean layout with Flexbox and CSS positioning

## Crafted with CSS

A frontend practice project exploring CSS styling, positioning, and creative design.
